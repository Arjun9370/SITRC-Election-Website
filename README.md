# 🗳️ SITRC Election Website

A demo **Student Election Voting Website** developed by **Arjun & Rohit** using **Google Apps Script**.

The project provides a simple and secure-style voting flow where demo students can log in using their **ERP ID and Date of Birth (DOB)**, view their student information, select a candidate/option, and submit their vote.

## 🚀 Deployment

The application is deployed as a **Google Apps Script Web App**.

### Basic deployment process

1. Open the Google Apps Script project.
2. Add the required HTML and Apps Script files.
3. Connect the project with the required Google Sheet.
4. Select **Deploy → New deployment**.
5. Select **Web app**.
6. Configure the access permissions.
7. Deploy the application.
8. Copy the generated Web App URL.
